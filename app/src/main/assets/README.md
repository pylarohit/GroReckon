# Login Hero Image

Place your login screen illustration here.

## Accepted filenames (any one of):
- `login_hero.png`
- `login_hero.jpg`
- `login_hero.webp`

## How it works
The app automatically detects whichever file you drop here.
If no file is found it shows a fallback placeholder with the GROReckon cart icon.

## Recommended size
- Resolution: 1080 × 900 px (portrait illustration, landscape crop works too)
- Format: PNG with transparent background looks best on the white card layout

## Steps
1. Copy your image into `app/src/main/assets/`
2. Name it exactly `login_hero.png` (or .jpg / .webp)
3. Rebuild the project — the image will appear in the top half of the login screen
